# Asset notices

## Patchouli icons

The following files are derived from Mojang's Minecraft bookshelf artwork:

- `patchouli-icon-color.png`
- `patchouli-icon-monochrome.png`

Source: [Bookshelf JE4 BE2](https://minecraft.wiki/w/File:Bookshelf_JE4_BE2.png) on the Minecraft Wiki.

The color version shifts the bookshelf's wood palette toward purple. Its yellow pixel crescent is adapted from the logo shown in a user-supplied reference for [VazkiiMods/Patchouli](https://github.com/VazkiiMods/Patchouli). The monochrome version redraws the block as three outlined isometric faces and uses a smooth interpretation of the same crescent silhouette.
